# v1.0.0 - Reproducible yeast WGS case study

First portfolio release of the matched P11 Illumina / historical ONT consensus 2D analysis.

- Snakemake read-QC, alignment, indexed-BAM, coverage, normalized variant and alternate-SNP comparison workflow.
- Real P11 input provenance, deterministic preparation, pinned versions and measured nuclear QC / SNP overlap.
- Controlled ONT BQ13 vs BQ7 experiment: shared depth domain 0.80% vs 53.31% of nuclear reference.
- Reviewer-attributed six-locus IGV Web observations and two original screenshots.
- Regional three-locus caller audit: FORMAT/DP exclusions and a controlled BAQ sensitivity experiment.
- French project synthesis, reproducible demo instructions, 21 Python tests and full synthetic CI.

Start with [the README](https://github.com/Gaith2000korchid/yeast-wgs-comparison#readme) or [the French synthesis](https://github.com/Gaith2000korchid/yeast-wgs-comparison/blob/v1.0.0/docs/PROJECT_SUMMARY_FR.md).

Scope: an exploratory, reproducible case study. Legacy ONT data, unequal effective coverage and a baseline caller prevent accuracy or platform-ranking claims. The regional audit is not the original full-genome caller run. No independent variant truth, complete callable mask or modern ONT performance claim is included. Indels and structural variants are not compared. Full FASTQs/BAMs/VCFs are regenerated locally and are outside the source archive; the regional IGV ZIP remains available through the documented Actions export.

Implementation developed with AI assistance; IGV observations attributed to Gaith Korchid. Code is MIT licensed; third-party tools and datasets retain their own licenses.
