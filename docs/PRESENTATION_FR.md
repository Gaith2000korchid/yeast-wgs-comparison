# Analyse NGS Illumina / Nanopore

**Question / objectif :** Pipeline Snakemake : contrôle qualité, alignement, couverture, variants et investigation des discordances.

**Candidatures concernées :** Bioinformatique NGS, génomique, ingénierie de recherche, Python scientifique.

**Preuves consultables :** Données réelles P11, résultats documentés, tests unitaires et intégration synthétique.

**Limites :** Aucune vérité terrain indépendante ; caller ONT exploratoire sur des données historiques. Pas de classement des plateformes.

Consulter le README pour les commandes, l’origine des ressources et les résultats. La présence de tests ou d’une CI ne valide pas à elle seule les conclusions scientifiques.
